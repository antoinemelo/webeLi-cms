# Contribuer à la documentation

Les guides sont orientés tâches; les références dérivables sont générées; les décisions internes restent sous `internal/`. Ajoutez le front matter obligatoire, une source de vérité, des liens relatifs et une date de vérification. Exécutez `python3 tools/cms.py docs generate`, `python3 tools/cms.py docs check` et le validateur c26.
