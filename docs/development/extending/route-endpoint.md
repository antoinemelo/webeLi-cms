# Ajouter une route ou un endpoint

Déclarez la route dans la source canonique, appliquez garde et permission, déléguez à un service, définissez l’erreur contractuelle, ajoutez un test, régénérez routes/endpoints/OpenAPI et exécutez les validateurs. Évitez les déclarations dupliquées.
